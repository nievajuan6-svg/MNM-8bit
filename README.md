# MNM Trío · versión 8-bit

Prototipo alternativo del sitio de MNM Trío: un escenario pixel-art en 360° (HTML + CSS + JS, sin dependencias).
Abrir `index.html` en el navegador o servir la carpeta con cualquier servidor estático.

- Navegación: scroll, flechas, deslizar o menú. Tocá los objetos del escenario (amplis, cuadros, integrantes, flight case, carpeta, dossier).
- `noindex`: no se indexa en buscadores.

## Audios
Los instrumentos de la zona "Propuesta" suenan al tocarlos. Ver `assets/audio/LEEME.md` para enchufar las grabaciones.

## Nota sobre los videos
YouTube muestra "Error 153" si se abre `index.html` directo desde el disco (`file://`). Publicado o servido por http(s) funciona.
